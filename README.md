# Sistem Monitoring Kondisi Tanah pada Tanaman Sawi Hijau (Final)

Repository ini berisi kode final untuk Tugas Akhir:
**"Sistem Monitoring Kondisi Tanah pada Tanaman Sawi Hijau Menggunakan Beberapa Algoritma Pembelajaran Mesin Berbasis Mikrokontroler"**

**Penulis:** Elsha Firlie (2211511002)  
**Departemen:** Teknik Komputer, Fakultas Teknologi Informasi, Universitas Andalas

---

## 📁 Struktur Repository
- **`firmware-esp32/`** → Kode program final mikrokontroler ESP32 (Arduino IDE).
- **`mobile-app/`** → Kode aplikasi mobile "Smart AgriFIS" (Flutter).
- **`notebooks/`** → Jupyter Notebook untuk pelatihan dan evaluasi model Machine Learning.

## 🔧 Teknologi yang Digunakan
- **Mikrokontroler:** ESP32
- **Sensor:** RS485 Soil 7-in-1
- **Model Machine Learning:** Decision Tree
- **Aplikasi Mobile:** Flutter
- **Database:** Firebase Realtime Database
